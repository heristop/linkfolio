# Linkfolio Trademark Policy

This document explains how you can use the Linkfolio™ name and logo. It's meant to be read alongside the [Brand section of the README](README.md#brand), which summarizes the same rules briefly — this page goes into more detail.

## What this covers

This policy covers two things: the project name **"Linkfolio"**, and the project logo (`src/assets/img/linkfolio_logo.svg`). It does not cover the source code itself, which is licensed separately under MIT.

Linkfolio has been in continuous use as the name of this project since 2023. It is not a registered trademark — it's an unregistered ("common-law") mark, protected by ordinary use rather than by a registration filing.

## Relationship to the MIT licence

Linkfolio's code is MIT licensed, and that licence is generous: you can use, copy, modify, merge, publish, distribute, sublicense, and sell copies of the software, essentially without restriction.

What the MIT licence grants is copyright in the software. It says nothing about the project's name or logo, because copyright and trademark are different things. This document doesn't take anything away from the MIT grant — it just spells out what MIT never covered in the first place, so nobody is caught by surprise later.

## Uses that are always fine — no permission needed

You don't need to ask before you:

- Refer to Linkfolio factually — "built with Linkfolio," "a fork of Linkfolio," "compatible with Linkfolio," and similar honest descriptions of a relationship to the project.
- Write tutorials, articles, reviews, comparisons, or give talks about Linkfolio.
- Link to the [Linkfolio repository](https://github.com/heristop/linkfolio).
- Redistribute the project itself, unmodified, under the terms of the MIT licence.

This kind of nominative, descriptive use is exactly what a project name is for, and we'd like people to keep doing it.

## Uses that need permission

Please check in first if you want to:

- Use the Linkfolio name or logo as the identity of a derivative or competing product.
- Put "Linkfolio" (or a confusingly similar name) in a company name, product name, or domain name.
- Put the name or logo on merchandise.
- Use the name or logo in advertising, or in any way that could suggest endorsement, sponsorship, or official status that doesn't exist.

None of this is meant to be unfriendly — it's just there to keep "Linkfolio" meaning one specific project, so the name stays useful to everyone who relies on it, including you.

## Forks specifically

Forking Linkfolio is welcome and encouraged; that's the point of an MIT licence. If you're publishing a fork as your own product, though, please give it its own name and its own logo rather than shipping it as "Linkfolio." You're still free to say, truthfully, that your project is a fork of or derived from Linkfolio — that's exactly the kind of factual reference described above.

## Logo usage

When you do use the Linkfolio logo (in the always-fine cases above, e.g. an article or a "built with" mention), please keep it intact:

- Don't stretch, squash, recolor, or apply effects (drop shadows, outlines, gradients, etc.) to the logo.
- Leave a reasonable amount of clear space around it rather than crowding it against other elements.

## Requesting permission

If you're not sure whether your use needs permission, or you'd like to ask for it, please [open an issue](https://github.com/heristop/linkfolio/issues). That's the only official channel for this — there's no separate trademark contact address.

## Changes to this policy

This policy may be updated from time to time as the project grows. The version in this repository is always the current one.
